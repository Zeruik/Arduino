## 工程与内存证据

部署配置保持**Q4权重+INT8 KV**，N16 ctx512、N32 ctx1024。N16/N32实际Q4=13,710,208/15,659,904 B，词表184,996/423,154 B；模型分区剩余445,568/3,200 B。INT8 KV=5,203,968/10,407,936 B；主机FP32 KV对照20,185,088/40,370,176 B，超过相应板PSRAM，不能按此直接部署。未测实体板峰值内存或速度。

保留已通过的C/HF反量化logits对拍、4000汉字HF/C token ID和往返、真实主机HTTP提交/生成/reset、UTF-8边界/canary/KV回退检查。HTTP及4000字只是工程能力，不能证明中文综合知识掌握。

最终R3可烧录包是**原R3模型+第4轮修复后的固件**，N16/N32固件974,528/975,120 B，与R5包固件hash相同。本轮未改C/Arduino、未重编、不改变R3模型；新包仅完成可复核重打包。四个R3/R5实际包再次通过manifest、地址、文件尺寸、SHA校验，见round6-package-checks.json。旧R3历史包也保留，其固件版本不同，应以最终R3可烧录包作工程复测。

Windows安装器含导入/烧录前包损坏、型号、文件、偏移/尺寸/hash校验。已在真实Windows CI做9项源码逻辑检查并产出Inno Setup exe；交付EXE大小26,737,365 B，SHA-256 `225893f8e16d21b303a139ee5d40081198fd4312ef7d8ff8539ebf89bd567679`。这不包含安装GUI、Windows真实串口或实体烧录实测。

## 实体板与Windows尚缺的验收材料

无需硬件的本轮计划检查已执行并交付，知识目标本身未完成。实体板阶段需要：

1. 两种实际模块完整丝印、载板型号和USB连接方式。当前N16为QIO Flash/OPI PSRAM；N32按WROOM-2 N32R16V的OPI/OPI配置，不能仅凭“32MB”字样视为相同硬件。
2. 115200 UTF-8串口从断电冷启动开始的完整日志：芯片/Flash/PSRAM识别、映射及模型初始化、固件/模型hash、KV分配、空闲/最小heap/PSRAM、复位原因。现有日志字段不足时需在拿到硬件后再补测，不假造现成数据。
3. 断开外网后的串口及热点网页原始多轮问答、/reset、长输入/上下文边界、重复冷启动与连续运行记录；记录输入/输出token数、首token与总耗时、峰值/最低剩余内存、异常与重启。
4. Windows版本、安装路径、真实COM口、导入/重导入、错误型号/损坏拒绝、烧录成功/失败退出、卸载等实际交互记录。Linux逻辑检查、CI打包及PE文件头不替代这些记录。

没有上述证据，实体板与Windows交互继续标记**未验收**。六轮自动任务到此暂停；不会再自动训练、延长轮数或另建持续任务。
