# 开源经验与设计依据

调研日期：2026-11-13。上游项目公开数字属于其作者的报告，不是小白的实测。

| 项目 | 可借鉴经验 | 本项目取舍 |
|---|---|---|
| [DaveBben/esp32-llm](https://github.com/DaveBben/esp32-llm) | llama2.c 在 ESP32 上运行，权重、KV 和工作区必须分别预算 | 学习微控制器推理路径；英文故事权重不能直接变中文聊天 |
| [slvDev/esp32-ai](https://github.com/slvDev/esp32-ai) | PLE 把大部分参数变成 Flash 查表，减少每 token 计算量 | 只借鉴存储分层；其 TinyStories 目标不提供问答和事实知识 |
| [jiaheng0815/feng-30m](https://github.com/jiaheng0815/feng-30m) | 中文教师蒸馏、Qwen3 小结构、Q4 Flash mmap、Q2 KV、共享 C 引擎 | 选择为适配底座，保留许可和来源，独立做小白继续训练与产品集成 |
| [HF 模型卡](https://huggingface.co/jiaheng0815/feng-30m) | 明确披露 PC 与 embed 权重不同，短题过关不代表泛化能力 | 不套用上游成绩；每份导出重新测量 |
| [乐鑫分区说明](https://docs.espressif.com/projects/arduino-esp32/en/latest/tutorials/partition_table.html) | Flash 容量、分区与烧录偏移需一致 | 每个型号单独分区表和包清单，自动检查重叠与越界 |

首选迁移学习而非 CPU 从零预训练：中文底座已经吸收了大规模预训练；当前环境没有可用 GPU。
N16R8 词表从 16384 裁成 8192，使用保持依赖闭合的 BPE 前缀，仍保留字节回退。
4000 汉字可编码不等于掌握 4000 字，也不等于可以容纳 4000 字上下文。
N32R16 保留原词表并增加上下文；两者均默认 Q4 权重，因此区别不止是量化等级。

## 当前配置

| 项目 | N16R8 | N32R16 |
|---|---:|---:|
| Flash / PSRAM | 16 / 8 MiB | 32 / 16 MiB |
| 层数 / 宽度 / FFN | 11 / 448 / 896 | 11 / 448 / 896 |
| BPE 词表 | 8192 | 16384 |
| 权重量化 | Q4 block64 | Q4 block64 |
| KV 量化 | INT8 | INT8 |
| 上下文配置 | 512 token | 1024 token |
| KV 精确字节数 | 5203968 | 10407936 |

512/1024 是 token 上限，输入、历史和输出共享；汉字可能拆成多个 token。
N32 的 Flash/PSRAM 电气配置暂按 WROOM-2 N32R16V（OPI/OPI），实物不同必须调整。
N16 暂按 QIO Flash / OPI PSRAM。型号、启动和速度最终都要实物验证。

## 训练数据和评估边界

使用固定 SHA-256 验证的上游教师数据包，加 TechABJ 人工整理的现代中文基础问答。
教师原始输出包含错误，不当作权威知识来源。训练/验证按精确问题去重，尚未证明语义无泄漏。
开发题会随迭代被观察，不再称作完全未见的盲测；发布前需另冻结独立测试集。
关键词提示只帮助定位问题，不能代替人工阅读，也不输出为“准确率”。
最初版本身份沿用 feng、欧姆定律回答错误：已记为失败候选，不能作为合格模型发布。

## 验证层级

1. 权重导出、哈希、分区与尺寸检查。
2. 4000 汉字往返、HF/C tokenizer ID 一致性。
3. 真实 Q4 文件反量化后的 HF/C 数值对拍。先使用 fp32 KV 隔离权重计算误差。
4. 实际部署配置 Q4/INT8 的原始短问答、多轮和输入边界测试。
5. HTML 服务真实推理、移动端布局、提交与清空测试。
6. 两种 Arduino 固件交叉编译；Windows 安装器在 Windows CI 构建。
7. 真板冷启动、断网、串口/热点网页、连续对话、峰值堆内存与掉电重启。

没有板端串口日志时，第 7 项必须保持未验收；不引用上游速度作为小白速度。

## 2026-11-13 缓存对照

同一 N16 Q4 候选在 fp32 KV 和 INT8 KV 下正确回答小白身份、欧姆定律、太阳分类；Q2 KV 下退化明显。因此部署默认改为 INT8，N32 上下文从 2048 缩短至 1024。这个取舍不增加权重文件体积。初版 Q2 报告留档，不能冒充 INT8 的成绩。
